Importing from China to Jordan — Questions & Answers

Every figure below is from the market data snapshot of 2026-08-23, with the source named in each answer. Items not yet verified are explicitly marked.

How large is China–Jordan trade?

China's exports to Jordan reached USD 182.6 million (ESTIMATED) in 2024 (USD 182,620,094), measured at the HS-6 leaf (reported, non-aggregate) level. This is a partial/lower-bound figure: the UN Comtrade preview API caps each response at 500 rows and mixes HS aggregate-level with 6-digit leaf rows, so a simple total row-sum (USD 699 million) double-counts and must NOT be used. Treat the leaf value as indicative/partial, NOT an authoritative total. Source: UN Comtrade public preview API (reporterCode=156, period=2024, flowCode=X, partnerCode=400, leaf rows), retrieved 2026-08-23.

What tariffs apply to imports from China into Jordan?

Jordan has been a WTO member since 2000-04-11. Two preferential arrangements apply: the US–Jordan FTA (entered into force 2001-12-17, and eliminated duties from 2010-01-01) and the EU–Jordan Association Agreement (since 2002). Jordan also participates in GAFTA, but that could not be confirmed from a reachable official source this session — Data gap. Exact duty rates depend on the HS code and are confirmed at order time; treat any single figure as indicative and confirm the latest official release. Sources: WTO, USTR, EU, retrieved 2026-08-23; GAFTA = Data gap.

What VAT / sales tax applies to imports into Jordan?

Jordan's standard sales tax (VAT-equivalent) rate is 16%. Reduced or exempt treatment can apply to certain categories. Verify the current rate with the relevant Jordanian tax/customs authority before import — treat any single figure as indicative only. Source: Trading Economics country-list sales-tax rate (Dec 2026), retrieved 2026-08-23.

What certification is required to import goods into Jordan?

Data gap: the Jordan Institution for Standards and Metrology (JISM) is the country's standards and conformity body, but all its domains were unreachable this session, so mandatory certification/standards requirements could not be verified from an official primary source. Confirm category-specific conformity requirements with the competent authority before import. Source: JISM — sites unreachable (Data gap), retrieved 2026-08-23.

What does Jordan import from China?

Jordan's top China-import HS-6 codes (partial leaf rows, by primaryValue) are HS 120600 (~USD 14.05 million), HS 121299 (~USD 13.73 million), HS 120991 (~USD 8.75 million), HS 120242 (~USD 7.53 million) and HS 160413 (~USD 6.55 million). NOTE: the UN Comtrade preview API did not return commodity description text (cmdDesc = null), so the HS codes and values are valid and traceable but product names could not be confirmed this session. Source: UN Comtrade public preview API (reporterCode=156, partnerCode=400, leaf rows), retrieved 2026-08-23.

What are the main ports and land routes for imports from China to Jordan?

Aqaba (on the Red Sea) is Jordan's main commercial port and its only deep-water port; Levant land routes include the King Hussein Bridge (Allenby/Al-Karameh crossing) toward Israel/Palestine and crossings toward Syria, Iraq and Saudi Arabia (e.g. Jaber, Al-Omari). Port names are stable geographic/logistics facts, but no official source was reachable this session to cite — so the route evidence is marked Data gap. Confirm route and port specifics with your forwarder at order time.
